Download & installالتحميل والتثبيت

From download to ribbon — step by stepمن التحميل إلى الريبون — خطوة بخطوة

The file is a ZIP so browsers download it without warnings. Follow these six steps.الملف مضغوط (ZIP) لتتجاوز حجب المتصفحات. اتبع الخطوات الست.

1

Download the ZIPحمّل الملف المضغوط

Click Download. Your browser saves EMOCAD_V1_Setup.zip (about 56 MB) to your Downloads folder.اضغط تحميل. يحفظ المتصفح ملف EMOCAD_V1_Setup.zip (حوالي 56 ميجابايت) في مجلد التنزيلات.

Tip: the download comes straight from the official GitHub release page.ملاحظة: التحميل مباشر من صفحة إصدار GitHub الرسمية.
2

Extract the ZIPفُكّ الضغط

Right-click the downloaded file and choose Extract All. A file called EMOCAD_V1_Setup.exe appears.انقر يمين على الملف واختر Extract All / استخراج الكل. يظهر ملف باسم EMOCAD_V1_Setup.exe.

Tip: Windows extracts ZIP files on its own — no extra program needed.ملاحظة: ويندوز يفكّ ملفات ZIP بنفسه — بلا برنامج إضافي.
3

Run it, then “Run anyway”شغّله ثم “Run anyway”

Double-click the setup. If Windows shows a blue “Windows protected your PC” screen, click More info then Run anyway.انقر مرتين على المثبّت. لو ظهرت شاشة زرقاء “Windows protected your PC”، اضغط More info ثم Run anyway.

Normal for new tools: the warning appears because the app isn't code-signed yet — it's safe. You can also scan it on VirusTotal.طبيعي للأدوات الجديدة: التحذير يظهر لأن البرنامج غير موقّع بعد — وهو آمن. تقدر تفحصه على VirusTotal.
4

Allow administrator accessاسمح بصلاحية المدير

Windows asks permission to make changes. Click Yes — the installer needs it to register the ribbon for AutoCAD.يطلب ويندوز إذناً بإجراء تغييرات. اضغط Yes / نعم — المثبّت يحتاجها لتسجيل الريبون في أوتوكاد.

5

Choose your AutoCAD versionsاختر إصدارات أوتوكاد

The installer detects the AutoCAD versions on your PC. Select all, or only the ones you use, then continue to the end.يكتشف المثبّت إصدارات أوتوكاد على جهازك. اختر الكل أو ما تستعمله فقط، ثم أكمل حتى النهاية.

6

Open AutoCAD & activateافتح أوتوكاد وفعّل

Open AutoCAD — the EMOCAD ribbon loads automatically. Type KEE to open the licence window and activate, or start the free trial.افتح أوتوكاد — يظهر ريبون EMOCAD تلقائياً. اكتب الأمر KEE لفتح نافذة الترخيص والتفعيل، أو ابدأ التجربة المجانية.

Ribbon missing after switching workspace? Type EMORIBBON to bring it back.اختفى الريبون بعد تبديل مساحة العمل؟ اكتب EMORIBBON لإرجاعه.
